# Attachments and Files

Paste an image (or drop any file) into the editor and Clew saves it to the
**attachment folder** (Settings → Files, default `Attachments/`) and inserts
an embed. Clicking an image, PDF, audio, or video file in the explorer opens
it in a **viewer tab**; `[[links]]` to attachments open the viewer too.
