# Graph View

**⌘G** opens the global graph: every note, sized by how linked it is,
laid out by a force simulation.

- **Scroll** to zoom (labels appear as you zoom in), **drag the
  background** to pan, **drag a node** to rearrange.
- **Hover** a note to highlight its neighborhood.
- **Click** a note to open it (⌘-click for a new tab).

The right sidebar's **Graph** tool shows the same thing scoped to the
active note's immediate neighborhood — see [[Panels]].
